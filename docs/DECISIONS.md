## د. ما نحتاج اعتماده أولاً قبل كتابة كود الإنتاج
الدفعة الأولى من قرارات الاعتماد: P-01 إلى P-08، ثم O-02 وO-03 وO-04 وO-11 وO-12؛ وفي نفس الوقت يمكن تطوير الكتالوجات وواجهات إدخال نموذجية باستخدام بيانات اختبار دون انتظار ماركات الأجهزة أو أعداد الحيوانات.

## هـ. تجميد نطاق الإصدار الأول مقابل التطوير اللاحق
- **أساسي في أول إصدار تشغيلي:** Farm/Field/Season، المهام الميدانية Offline، الحقول/الري/المياه، الحيوان والقطيع، الحوض السمكي والسجل الصحي/العلف، الصوبة ومراقبة المناخ، المخازن/التكلفة المرجعية، صيانة/معدات، التنبيهات الأساسية، صور الأقمار مرفوعة يدوياً، موصل Import عام، صلاحيات وموافقات أساسية.
- **يتوسع في إصدارات لاحقة دون إعادة تصميم قاعدة البيانات:** موصلات تلقائية حسب أجهزة المورد، تحكم آلي مفوض، تحليل Sentinel متقدم، Time Series على نطاق واسع، نماذج توقع، SCADA/PLC كامل، تخطيط رقمي للصوب/الأسماك، تحليل مرئي متقدم، وتطبيقات محاسبية تفصيلية حسب الحجم.
- كل بند ضمن نطاق البرنامج النهائي، وتختلف فقط أولوية التنفيذ والاعتماد والموارد.

## و. معيار «جاهز لبدء البرمجة»
1. تقرر الحدود بين ERPNext و`wadi_farm` وMobile وEdge.
2. تُثبت أسماء DocTypes الأساسية وID conventions والحقول الإلزامية.
3. يُعتمد workflow لكل معاملة مؤثرة في المخزون/المال/السلامة.
4. تُعتمد سياسة المخزون والتكاليف والعمليات Offline والتعارض.
5. تُعتمد النسخ الاحتياطية والتجريب وتغييرات الشبكة والربط الخارجي.
6. يوجد اختبار قبول لكل وحدة ونسخة ترقية بدون فقد بيانات.
